# VisaDone 图标主体

原创矢量主体：护照、地球与完成勾。透明画布，不含背景底板、系统圆角遮罩、阴影、渐变或预制玻璃效果。

## 文件

- `VisaDone-subject.svg`：完整主体，四组可编辑路径。可直接导入 Icon Composer。
- `layers/`：相同 1024 × 1024 透明画布上的独立图层，按 01–04 顺序由后向前导入。各层坐标已经对齐，无需分别居中或缩放。
- `VisaDone-subject-preview.png`：透明背景预览，仅供检查形状。

## 构图与配色

以稍微倾斜的护照形体表达签证申请；大号完成勾是主要识别点。地球作为次要细节，在小尺寸下不承担识别任务。

- 封面：`#2D897B`
- 书脊：`#135E54`
- 地球：`#DBEFE7`
- 完成勾：`#F8FCF8`

在 Icon Composer 中另设背景和材质。主体的旋转已写入各 SVG；不要对每层单独“适合画布”，否则会破坏对齐。白色细节是实体前景图层，而非透明镂空，便于单独设置材质。

只新增设计文件，未替换应用当前图标。
