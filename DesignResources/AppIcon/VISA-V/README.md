# VISA 字标的 V

仅保留 VISA 字标中的 V，无背景、字体依赖或效果。

- `VISA-V.svg`：紧贴字形边界，保持原始比例。
- `VISA-V-1024.svg`：1024 × 1024 透明画布，主体居中，适合继续导入 Icon Composer。
