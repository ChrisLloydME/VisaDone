# 社区封面与首屏编排

- 材料类封面 `visaCoverAccommodation` 使用内置 image_gen 生成，完整提示词见 `prompts.json`。
- 构图参考 [xhs-cover-skill](https://github.com/Vivixiao980/xhs-cover-skill) 的简洁大字与分层排版方向；项目 README 声明 MIT。未导入其代码或参考人物照片。
- **所有风景图直接使用既有 Covers 原图，不加文字、不重生成。**
- 申请清单和行程长页主要保留在详情图片中，首页只穿插少量，避免首屏变成文档墙。
- 应用使用的生成封面保存在 `VisaDone/Assets.xcassets/CommunityCovers/`。
